# Python Data Engineering Interview Practice

## Files
- `employees.csv` — 50 employee records
- `customers.csv` — 100 customer records
- `transactions.csv` — 500 transaction records
- `orders.json` — 100 nested orders
- `employees.xlsx` — employee data in Excel
- `python_interview_solutions.py` — numbered reference solutions for the 390-question plan
- `PYTHON_CONCEPTS.md` — OOP, attributes, constructor/destructor, decorators, lambda, generators, exceptions, concurrency and DE concepts

## Recommended workflow
1. Attempt each question without opening the solution.
2. Run your code against the datasets.
3. Compare with the reference only after getting stuck.
4. Refactor procedural solutions into functions.
5. Later convert suitable logic into Pandas/SQL/ETL pipelines.
